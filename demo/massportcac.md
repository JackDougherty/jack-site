# Demo interactive maps for Massport CAC

Updated: All of these demo maps are created in a free professional-quality tool called Datawrapper, with the source data pulled from [this linked public Google spreadsheet](https://docs.google.com/spreadsheets/d/1ZQ1fwM4m66dcpvX1KtuQacILnt4LE_EIiKrVu5h5Z7g/edit?usp=share_link) as shown below. Source data also can be linked or pasted directly from an external Excel spreadsheet.

## Three map design options
1. One solid color vs. Randomized multi-colors (to help viewers differentiate municipalities). All colors can be modified.
2. No labels at start vs. 10 labels at start (to orient viewers to geography). The initial number and placement of labels can be customized.
3. Show all MA municipal outlines (to inform viewers which areas do and do not participate).

Additional options: initial size of map on web page (demos show 650 pixels tall), zoom level, text, etc.

Note that City of Boston has 7 appointees from 23 designated neighborhoods, so I decided to group all of them into the Boston polygon and list their neighborhood in parentheses after their name, such as: Alan Wright (Roslindale). This also was the simplest geographical solution. A more complex geographical solution would attempt to show the 23-neighborhood boundaries inside the City of Boston, but most of these would be blank because there are only 6 appointees.


Note: Drafts 6-7-8 use one solid color and focus on the metro Boston region
